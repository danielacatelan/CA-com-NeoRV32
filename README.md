# Computação Aproximada no Processador RISC-V NEORV32

Este repositório demonstra como integrar instruções aproximadas no processador NEORV32 e como utilizar ferramentas de EDA para análise dos ganhos e custos.

O projeto de instruções aproximadas inclui operações de inteiros (addx, subx, mulx, divx), que fazem parte da tese de doutorado da Prof(a) Daniela Luiza Catelan da Universidade Federal de Mato Grosso do Sul (UFMS), daniela.catelan@ufms.br, sobre "Exploração do Espaço de Design com Computação Aproximada".

## Pré-requisitos

O seguinte guia deve ser seguido para baixar, configurar e usar as ferramentas RISC-V: [RISCVTools.md](./docs/RISCVTools.md)

## Documentos

Estes artigos introduzem os conceitos básicos de Computação Aproximada. 

[SurveyPart1](./files/Survey_LEON_Part1.pdf): Apresenta as motivações para a implementação estudo, terminologias e princípios, demonstrando técnicas de aproximação aplicadas tanto em software quanto em hardware, essenciais para entender a base. 

[SurveyPart2](./files/Survey_LEON_Part2.pdf): Se aprofunda mais em aplicações específicas(domains, quality metrics, benchmarks) e apresenta técnicas de aproximação em arquitetura.
